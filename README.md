# Sonal Mirani — Resume & Portfolio Website

A responsive, editorial-style single-page resume website built with HTML, CSS and basic JavaScript.

## Files

- `index.html` — page structure and resume content
- `css/style.css` — layout, colours, typography and responsive styling
- `js/script.js` — mobile navigation interaction
- `assets/documents/` — place your resume PDF here if you want to add a download link later

## Run locally

1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or open the file directly in a browser.
4. Keep the folder structure unchanged so the CSS and JavaScript paths work.

## Before publishing

Replace the contact placeholders in `index.html`:

- `[Your Email]`
- `[Your Phone Number]`
- `[Your LinkedIn Profile]`

Check all dates, qualification statuses and institution names before making the website public.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload the contents of this folder (not the ZIP file itself).
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save. GitHub Pages will publish the site.

The website uses relative asset paths and does not require a backend or build process.
